# Al Fajar Studio v1.0.0

Initial release of **Al Fajar Studio**, a Windows desktop application designed to manage studio bookings efficiently and conveniently.

### Features

* 📅 Booking management
* 💾 Local booking data storage
* 🖥️ Windows desktop application
* 📁 Automatic data folder setup
* 🚀 Easy installation with Windows installer
* 🔄 Backup support for booking data

### Installation

1. Download **AlFajarStudio-Setup-v1.0.0.exe** below.
2. Run the installer.
3. Follow the installation steps.
4. Launch **Al Fajar Studio** from the Desktop or Start Menu.

### System Requirements

* Windows 10 or later
* No additional installation required

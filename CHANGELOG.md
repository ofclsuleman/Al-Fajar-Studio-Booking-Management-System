# Changelog

## Version 1.0.0 — 2026

### Added
- Secure password login
- User profile session handling
- Al Fajar Studio dashboard
- Multi-step booking wizard
- Dynamic event day management
- Date picker controls
- Event and timing selection
- Custom event and timing support
- Equipment setup per event day
- Custom equipment support
- Deliverables management
- Custom deliverable support
- Payment fields for Total Charges and Advanced Received
- Local JSON booking database
- Automatic booking ID generation
- Booking search
- Booking details screen
- Booking editing
- WhatsApp-ready confirmation messages
- Automatic clipboard copying
- Safe local JSON save procedure
- Error handling for invalid input and data-file problems

### Notes
- Core functionality works offline.
- Booking data is stored in `Data\bookings.json`.
- No remaining, outstanding, or balance amount field is maintained.
